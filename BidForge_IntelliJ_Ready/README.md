# BidForge - IntelliJ Ready

This version contains the requested RFQ/Vendor quotation fixes.

## Vendor quotation flow
- Vendor can update/resubmit the same RFQ quotation while the RFQ is OPEN and the quotation is not APPROVED.
- Resubmission replaces the old quotation item rows safely and recalculates 10% GST and total amount.
- Save Draft was removed from the vendor quotation page.
- Remarks and amounts are persisted with `saveAndFlush`.
- Bid No is generated by the server and displayed as the actual number.

## Invoice flow
- Admin approval does NOT mark the invoice as generated.
- Only the vendor can click **Generate Invoice** after Admin approval.
- No PDF is created and no invoice PDF page is used.
- After the vendor generates it, both Vendor and Admin see `Generated`.
- `InvoiceGenerated` is stored in `RFQQuotations`; `spring.jpa.hibernate.ddl-auto=update` will add the column to an existing database.

## UI
- Bootstrap 5.3.3 is used for components.
- `app.css` is only for layout/alignment/theme (sidebar, spacing, responsive tables, toolbar/pagination).
- Blue primary styling was removed from statuses/actions.
- Search and pagination controls are Bootstrap-aligned.

## IntelliJ
Open the extracted folder containing `pom.xml` in IntelliJ IDEA, reload Maven, select the configured JDK (Java 21), and run `BidForgeApplication`.
